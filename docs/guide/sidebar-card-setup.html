Guide / GitHub visibility

Make your funding visible.

The Sponsor card needs both a FUNDING.yml file and a repository-level Sponsorships setting.

01

What to add

Put .github/FUNDING.yml on the default branch with valid usernames and no secrets.

02

What to enable

Open Settings → General → Features and enable Sponsorships.

03

How to test

Use an incognito window, open the Sponsor button, and test every route.
