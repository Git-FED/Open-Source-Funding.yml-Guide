Open-source funding, made practical

Make the ask visible.
Make the path resilient.

Most guides list platforms. This one helps maintainers choose a small funding setup, understand what they actually keep, and put the right link in the GitHub sidebar.

The central idea

You are not only choosing a platform. You are choosing which payment methods a supporter can use.

The smallest useful setup

A single link can create a payment wall. Two complementary links usually cover more supporters than six overlapping brands.

.github/FUNDING.yml
github: [YOUR_USERNAME]
ko_fi: your_handle
custom: [https://your-payment-link]
